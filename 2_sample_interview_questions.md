# Sample Interview Questions (Reference Set — for testing, not hardcoding)

These are common, widely-asked question types per role, collected as a reference set to test the grading system against. Use these to generate test cases — don't hardcode them as the only questions the system recognizes.

---

## 1. SDE (Software Development Engineer)

**Technical:**
1. Reverse a linked list (iterative and recursive).
2. Given an array of integers, find two numbers that add up to a target value (Two Sum).
3. Explain the difference between a process and a thread.
4. Design a URL shortening service (system design, high-level).
5. What happens when you type a URL into a browser and press Enter?
6. Find the first non-repeating character in a string.
7. Explain the four pillars of Object-Oriented Programming with examples.
8. Given a binary tree, check if it's balanced.
9. How would you design a rate limiter?
10. What is the difference between SQL and NoSQL databases, and when would you choose one over the other?

**Behavioral (for SDE rounds):**
- Tell me about a time you disagreed with a teammate's technical decision. What did you do?
- Describe a bug that was especially hard to track down. How did you find it?
- Tell me about a time you had to learn a new technology quickly for a project.

---

## 2. HR Round (General/Fit)

1. Tell me about yourself.
2. Why do you want to work at this company?
3. Where do you see yourself in 5 years?
4. What are your greatest strengths and weaknesses?
5. Describe a time you failed at something. What did you learn?
6. Why are you leaving your current role? (or: why this career switch?)
7. Tell me about a conflict you had with a coworker and how you resolved it.
8. How do you handle tight deadlines or pressure?
9. What's a project you're most proud of, and why?
10. Do you have any questions for us?

---

## 3. Data Analyst

**Technical:**
1. Write a SQL query to find the second-highest salary in an Employees table.
2. What is the difference between INNER JOIN and LEFT JOIN?
3. How would you handle missing data in a dataset?
4. Explain the difference between correlation and causation.
5. What is A/B testing, and how would you determine if a test result is statistically significant?
6. Walk me through how you'd approach a case study: "Our app's daily active users dropped 15% last week — how would you investigate why?"
7. What's the difference between a primary key and a foreign key?
8. Explain what an outlier is and how you'd decide whether to remove one from analysis.

**Behavioral (for Data Analyst rounds):**
- Tell me about a time your analysis changed a business decision.
- Describe a time you had to explain a technical/data finding to a non-technical stakeholder.
- Tell me about a time you found an error in your own analysis after presenting it. What did you do?
